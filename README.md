# 党章考试在线练习

一个面向党章考试 / 入党积极分子考试复习的在线刷题网页。项目采用纯前端实现，打开浏览器即可使用，支持单选、填空、简答、论述等题型，适合考前自测、错题复盘和高频知识点回顾。

> 项目定位：课程作业 / 个人复习工具 / 静态网页练习项目  
> 当前版本：本地单机版，学习记录保存在当前浏览器中

---

## 项目预览

项目运行后可以使用以下功能：

- 按题型练习：单选题、填空题、简答题、论述题
- 按知识模块筛选：根据党章相关知识点分类复习
- 多种练习模式：顺序刷题、随机抽题、错题重练、收藏复习
- 高频速背：集中回顾常考知识点和易混内容
- 模拟考试：按设定题量进行考前自测
- 错题本：自动记录答错题目，便于后续复盘
- 收藏题：手动收藏重点题目，形成个人复习清单
- 本地保存：学习进度、错题和收藏记录保存在浏览器中
- PWA 支持：包含 `manifest.json` 与 `service-worker.js`，可作为网页应用使用

## 技术栈

本项目不依赖后端服务，也不需要复杂构建工具。

| 类型 | 技术 |
|---|---|
| 页面结构 | HTML5 |
| 页面样式 | CSS3 |
| 交互逻辑 | JavaScript |
| 数据存储 | localStorage |
| 题库文件 | questions.js |
| 离线支持 | Service Worker |
| 部署方式 | Netlify / GitHub Pages / Vercel |

## 项目结构

```text
党章/
├── index.html              # 页面入口
├── style.css               # 页面样式
├── script.js               # 核心交互逻辑
├── questions.js            # 题库数据
├── manifest.json           # PWA 配置
├── service-worker.js       # 离线缓存脚本
├── icon.svg                # 网站图标
├── README.md               # 项目说明文档
├── DEPLOY.md               # 部署说明
└── materials/              # 复习资料来源，仅作整理参考
```

说明：

- 网站实际运行主要依赖 `index.html`、`style.css`、`script.js`、`questions.js`。
- `materials/` 中的资料主要用于题库整理参考，部署公开网站时可以根据需要选择是否上传。
- 如果资料涉及课程内部文件或不适合公开传播，建议不要上传到公开 GitHub 仓库。

## 本地运行

### 方法一：直接打开

双击 `index.html`，使用浏览器打开即可。

### 方法二：使用本地服务器运行（推荐）

在项目目录下打开终端，执行：

```bash
python -m http.server 5500
```

然后在浏览器访问：

```text
http://127.0.0.1:5500/index.html
```

这种方式更接近真实部署环境，适合测试缓存、脚本加载和 PWA 相关功能。

## 部署到线上

本项目是纯静态网页，可以免费部署到常见静态托管平台。

### GitHub Pages

1. 新建 GitHub 仓库，例如 `dangzhang-trainer`。
2. 上传项目文件，确保 `index.html` 位于仓库根目录。
3. 进入仓库 `Settings`。
4. 找到 `Pages`。
5. Source 选择 `Deploy from a branch`。
6. 分支选择 `main`，目录选择 `/root`。
7. 保存后等待 GitHub 生成访问地址。

### Netlify

1. 打开 Netlify。
2. 选择手动部署或拖拽部署。
3. 上传整个项目文件夹。
4. 等待生成网址。
5. 将网址发送给手机、平板或朋友即可访问。

### Vercel

1. 打开 Vercel。
2. 导入 GitHub 仓库。
3. 保持静态网页默认配置。
4. 点击部署。

## 数据保存说明

当前版本使用浏览器 `localStorage` 保存学习记录。

保存内容包括：

- 已练习题目
- 答题正确率
- 错题记录
- 收藏题目
- 部分练习状态

需要注意：

- 同一设备、同一浏览器中刷新页面后，记录会保留。
- 更换浏览器、清理缓存或换设备后，原记录不会自动同步。
- 如果需要账号登录和跨设备同步，需要额外接入 Supabase、Firebase 或自建后端数据库。

## 题库维护

题库位于：

```text
questions.js
```

每道题建议使用如下结构：

```js
{
  id: "single_001",
  type: "single",
  module: "党的思想路线",
  difficulty: "高频",
  question: "党的思想路线的第一项要求是（ ）。",
  options: ["一切从实际出发", "全面从严治党", "坚持群众路线", "坚持依法治国"],
  answer: "一切从实际出发",
  explanation: "党章规定，党的思想路线是一切从实际出发，理论联系实际，实事求是，在实践中检验真理和发展真理。"
}
```

字段说明：

| 字段 | 说明 |
|---|---|
| id | 题目唯一编号，不能重复 |
| type | 题型，可选 `single`、`blank`、`short`、`essay` |
| module | 知识模块或章节 |
| difficulty | 难度或标签，例如基础、高频、易错、主观题 |
| question | 题干 |
| options | 单选题选项，主观题和填空题可不写 |
| answer | 标准答案或参考答案 |
| explanation | 解析或记忆提示 |

添加题目后，建议打开浏览器控制台检查是否存在 JavaScript 语法错误。

## 常见问题

### 1. 页面能打开，但按钮没反应怎么办？

可以按顺序检查：

1. `questions.js` 是否存在语法错误。
2. `index.html` 是否正确引入 `questions.js` 和 `script.js`。
3. 浏览器控制台是否有红色报错。
4. 文件路径是否使用相对路径，而不是 `C:/Users/...` 这种本机绝对路径。

### 2. 为什么换设备后看不到学习记录？

当前项目是本地保存版，数据只保存在当前浏览器中。换设备、换浏览器或清理缓存后，学习记录不会自动同步。

### 3. 部署到 GitHub 后资料文件要不要上传？

如果只是运行网页，通常不需要上传 `materials/` 文件夹。该文件夹里如果包含课程资料、PDF、Word 文档或内部复习材料，建议不要上传到公开仓库。

### 4. 为什么修改题库后页面没变化？

可能是浏览器缓存或 Service Worker 缓存导致。可以尝试：

- 按 `Ctrl + F5` 强制刷新；
- 清除浏览器缓存；
- 临时注销或更新 `service-worker.js`；
- 修改缓存版本号后重新部署。
